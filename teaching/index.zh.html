    核心概念

    • 角谱
    • 空间频率
    • FFT
    • 倏逝波
    E02 / 短片 + 课程 + PYTHON 实验

    为什么透镜能做傅里叶变换

    透镜把不同方向的平面波分到不同焦点。第二片透镜再把频谱变回图像，让你能够在两者之间修改它。

    核心概念
    • 傅里叶变换
    • 4f 系统
    • 空间滤波
    • 相位衬度

    E05 / 短片 + 课程 + PYTHON 实验

    全息与相位问题

    将相位差变成可测的条纹，从旁带恢复复光场，并理解迭代约束能够确定什么、又无法确定什么。

    核心概念

    • 离轴全息
    • 相位恢复

    E06 / 短片 + 课程 + PYTHON 实验

    平面光学与相位包裹

    薄元件通过厚度控制相位。将相位包裹到一个周期内，可以得到很薄的光学元件；相位量化与波长变化则揭示这种简化的代价。

    核心概念
    • 相位包裹
    • 衍射光学
    • 相位量化
    • 色差
    • 薄元件近似
    E07 / 短片 + 课程 + PYTHON 实验

    • 布洛赫波
